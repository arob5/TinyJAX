# TinyJAX

[JAX](https://docs.jax.dev/en/latest/index.html)'s source code is rather difficult to follow. Following in the spirit 
of Andrej Karpathy's [micrograd](https://github.com/karpathy/micrograd), this repo seeks to implement a minimal 
JAX-like library:
- the only dependency is numpy
- JAX is a dev dependency for testing against tinyjax
